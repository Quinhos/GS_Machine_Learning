# Registro de utilização de Inteligência Artificial — TermoAtiva

## FIAP — Global Solution 2026.2

**Disciplina:** Inteligência Artificial & Machine Learning  
**Projeto:** TermoAtiva

## 1. Ferramenta utilizada

- Ferramenta: ChatGPT (OpenAI)
- Ambiente de desenvolvimento: Google Colab
- Linguagem: Python
- Principal algoritmo: Regressão Logística

## 2. Objetivo da utilização

A Inteligência Artificial foi utilizada como ferramenta de apoio ao aprendizado, à revisão de códigos e à interpretação de resultados.

O desenvolvimento foi realizado de forma incremental, com execução e conferência das células no Google Colab.

## 3. Exemplos de prompts utilizados

### Prompt 1 — Definição do projeto

"Vamos seguir com a ideia TermoAtivo, com a matéria de ML"

**Aplicação:** análise dos requisitos da Global Solution e definição do componente de Machine Learning da TermoAtiva.

### Prompt 2 — Desenvolvimento com dados reais

"seguinte, ja vamos começar o projeto usando esses datasets disponiveis, fazendo a conferencia inicial com eles."

**Aplicação:** elaboração incremental dos códigos para importar, verificar, tratar e analisar os dados históricos do INMET.

### Prompt 3 — Revisão acadêmica

"certo, confira no drive se está tudo ok e alinhado"

**Aplicação:** conferência das etapas de preparação, criação do target e separação de dados.

### Prompt 4 — Revisão do repositório

"acesse o github e confira se esta de acordo"

Finalidade: Verificar a estrutura do repositório, a localização dos arquivos e a apresentação do README.

O uso do ChatGPT contribuiu para o acompanhamento técnico, a conferência de resultados, a identificação de possíveis inconsistências e a organização dos materiais da TermoAtiva.
